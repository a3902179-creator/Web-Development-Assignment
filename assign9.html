Assignment 33: Create and Validate catalogue.json

Load the JSON file, parse its contents and validate the catalogue structure and product fields.

Click Load catalogue.json to begin. 

Catalogue data will appear here.

Validation Rules

  • The JSON must be valid and parseable.
  • A catalogue object and products array must exist.
  • Each product must have a unique numeric ID.
  • Name and category must be non-empty strings.
  • Price must be a non-negative number.
  • inStock must be a Boolean.
  • Specifications must be an object.
