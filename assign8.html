Assignment 29: Source Code, Output & Test Cases

Demonstration of JavaScript objects and nested data.

Sample Source Code

const student = {
    name: "Ansh",
    course: "BCA AI",
    address: {
        city: "Lakhimpur Kheri",
        state: "Uttar Pradesh"
    }
};

console.log(student.name);
console.log(student.course);
console.log(student.address.city);
console.log(student.address.state);
