ASSIGNMENT 50

Project Idea & User Requirements

Problem Statement

Students often manage assignments, deadlines and study goals across different places. This dashboard provides one place to organize tasks and monitor completion.

Target Users

School and college students managing assignments and study plans.

Core Features

  • Create, edit and delete tasks.
  • Set priority and optional due dates.
  • Mark tasks as completed or pending.
  • Filter tasks by status.
  • View task statistics and completion progress.
  • Save tasks and theme preference in browser storage.
  • Use the dashboard on desktop and mobile screens.

User Requirements

  1. Users must enter a task title to create a task.
  2. Users can select a priority and optional due date.
  3. Users can edit, complete and delete tasks.
  4. Users can filter tasks by completion status.
  5. Statistics update after task changes.
  6. Tasks should persist after refreshing the same browser.
  7. The interface should adapt to smaller screens.

Project status: Core implementation. Final testing and approval must be completed before calling the project release-ready.

User Flow

  1. Open the dashboard.
  2. Enter a task title, priority and optional due date.
  3. Select Add Task to save the task.
  4. View the task in the task list.
  5. Edit, complete or delete the task when needed.
  6. Filter the list by pending or completed status.
  7. Review updated statistics and project progress.

    ASSIGNMENT 53

    Architecture Notes

    HTML5

    Provides semantic sections, forms, navigation and task-list structure.

    CSS3

    Controls page layout, colors, themes, responsive styles and accessibility states.

    JavaScript

    Handles task operations, validation, filtering, statistics and user interactions.

    localStorage

    Stores task data and theme preference in the current browser.

    Core Utility Functions

    • StorageHelper.get() reads stored data safely.
    • StorageHelper.set() saves JSON data.
    • loadTasks() loads saved tasks.
    • saveTasks() persists task changes.
    • renderTasks() updates the task list and statistics.
    • createId() generates a unique task identifier.
